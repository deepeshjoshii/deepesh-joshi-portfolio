Project 03 · Live tools

Research Analysis Tools

Python · Streamlit · Quantitative Finance · Automation

Built and deployed automated research analysis tools in Python and Streamlit. The Beta Calculator automates market-data retrieval and covers regression beta, Blume adjustment, statistical diagnostics, rolling beta, bottom-up peer beta and multi-parameter sensitivity analysis. The Reverse DCF solves for the growth rate implied by the current market price using net income, FCFF or FCFE, and compares it with the company's historical growth. Together they automate data collection and calculation steps that are otherwise done manually in spreadsheets.
